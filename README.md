# govtech-hackaton-2026
Проект автоматической классификации инцидентов для Ситуационного центра г. Петропавловск.  
**Авторы:** Khan & Aslan

## Описание проекта
Скрипт обрабатывает текстовые сообщения из социальных сетей и мессенджеров с помощью Gemini API. Система распределяет входящие обращения по категориям (ЖКХ, Дороги, Экология, Общественный транспорт и др.), определяет уровень критичности инцидента и формирует строгое официальное обоснование для операторов Ситуационного центра.

## Инструкция по запуску (для Linux, macOS, Windows)

### 1. Открытие терминала
* **Linux:** Нажмите `Ctrl + Alt + T` или запустите терминал через меню приложений.
* **macOS:** Нажмите `Cmd + Space`, введите *Терминал* и нажмите Enter.
* **Windows:** Нажмите `Win + R`, введите `cmd` и нажмите Enter.

### 2. Переход в директорию проекта
Используйте команду `cd` для перехода в папку со скриптом:
```bash
cd /путь/к/папке/govtech-hackaton-2026

```

*В Linux и macOS можно ввести `cd ` и перетащить папку из файлового менеджера напрямую в окно терминала.*

### 3. Установка зависимостей

Установите необходимые библиотеки для работы со скриптом:

```bash
pip install pandas google-genai

```

*Если в Linux возникает ошибка прав доступа, используйте `pip3 install pandas google-genai` либо разверните виртуальное окружение (`python3 -m venv venv && source venv/bin/activate`).*

### 4. Конфигурация API-ключа

1. Откройте файл `analyzer.py`.
2. Вставьте актуальный токен в переменную `API_KEY` в начале файла.
3. При исчерпании суточных лимитов сгенерируйте новый ключ в [Google AI Studio](https://aistudio.google.com/) (в новом проекте или с другого аккаунта).

### 5. Запуск анализа данных

Убедитесь, что исходный файл `city_messages.csv` находится в одной папке со скриптом. Запустите выполнение:

* В Linux / macOS:

```bash
python3 analyzer.py

```

* В Windows:

```bash
python analyzer.py

```

Результат сохраняется в файл `analyzed_city_messages.csv`.

* **Язык разработки:** Python 3

* **Обработка данных:** Pandas
