# govtech-hackaton-2026

**Проект:** Интеллектуальная система автоматической классификации инцидентов для Ситуационного центра г. Петропавловск (СКО).  
**Авторы:** Khan & Aslan

---

## Описание проекта
Данный проект автоматизирует работу Ситуационного центра. Скрипт-анализатор на базе DeepSeek API (deepseek-chat) обрабатывает сырой поток обращений граждан из социальных сетей. Система автоматически классифицирует инциденты (ЖКХ, Дороги, Экология и т.д.), отсеивает флуд, выявляет критические угрозы и формирует сухие официальные обоснования. 

Результаты работы скрипта выводятся на интерактивный дашборд **Streamlit** для удобного мониторинга операторами центра.

---

## Зачем нужно виртуальное окружение `(venv)`?
Перед запуском проекта **критически важно** создать и активировать виртуальное окружение. 

**Что это такое:** Это изолированная «папка» с Python, в которую мы устанавливаем нужные библиотеки (Pandas, Streamlit, OpenAI). 
**Почему без него не работает сервер:** Если вы попытаетесь запустить `streamlit run app.py` без активации окружения, терминал выдаст ошибку, так как ваша операционная система будет искать библиотеку Streamlit в глобальных файлах компьютера, а не в файлах проекта.

Индикатором того, что вы всё сделали правильно, является надпись **`(venv)`** в самом начале строки ввода в вашем терминале.

## Пошаговая инструкция по запуску

Выберите вашу операционную систему и четко следуйте шагам.

### Вариант 1: macOS
1. **Откройте Терминал:** Нажмите `Cmd + Space`, введите `Терминал` и нажмите Enter.  
2. **Перейдите в папку проекта:**
```bash
   cd /путь/к/папке/govtech-hackaton-2026
```  
3. **Создайте виртуальное окружение (выполняется 1 раз):**
```bash
python3 -m venv venv
```  
4. **Активируйте окружение:**
```bash
source venv/bin/activate
```  
*(Убедитесь, что слева появилась надпись `(venv)`).*  
5. **Установите зависимости проекта:**
```bash
pip install pandas openai streamlit
```  
6. **Перейдите к разделу «Запуск проекта» (ниже).**

## Запуск проекта

После того как вы активировали `(venv)` и установили библиотеки, проект готов к работе. Запуск состоит из двух этапов.

### Шаг 1: Настройка API-ключа

Откройте файл `analyzer.py` в любом редакторе кода и вставьте актуальный API-ключ от личного кабинета DeepSeek (platform.deepseek.com) в переменную `API_KEY`.

### Шаг 2: Запуск ИИ-анализатора

Этот скрипт прочитает исходный файл `city_messages.csv`, отправит данные в нейросеть и сохранит готовый результат. Скрипт работает с паузами в 1.5 секунды для стабильной обработки.

* Команда для macOS/Linux: `python3 analyzer.py`
* Команда для Windows: `python analyzer.py`

*При возникновении ошибок (исчерпание лимита токенов) скрипт автоматически сбрасывает прогресс, включает таймер ожидания и начинает работу заново. Файл результата `analyzed_city_messages.csv` появится только после 100% успешной обработки всех строк.*

### Шаг 3: Запуск веб-сервера (Дашборд)

Чтобы визуализировать собранные данные, запустите локальный сервер Streamlit. Выполните команду в терминале (убедитесь, что `(venv)` всё еще активно):

```bash
streamlit run app.py
```

После выполнения команды в терминале появятся две ссылки (Local URL и Network URL). Скопируйте ссылку `http://localhost:8501` и откройте её в браузере. Там будет доступен интерфейс Ситуационного центра.

## ⚠️ Памятка при повторном открытии проекта

Если вы закрыли терминал и открыли его заново на следующий день, **Вам не нужно заново создавать окружение и скачивать библиотеки**.
Вам нужно только зайти в папку проекта и **включить** его:

* В macOS/Linux: `source venv/bin/activate`
* В Windows (cmd): `venv\Scripts\activate.bat`

Как только появится `(venv)`, можете сразу запускать `streamlit run app.py` или `python analyzer.py`.
